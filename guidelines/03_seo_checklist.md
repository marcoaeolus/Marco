# 03. SEO 체크리스트

검색 유입(Google, Daum/Kakao, Naver)을 의식한 최소한의 룰. 모든 글은 발행 전 이 체크리스트를 통과시킵니다.

## A. 키워드 설계 (작성 시작 전)

- [ ] **메인 키워드 1개** 결정 (예: "강릉 안목해변 카페")
- [ ] **서브 키워드 2~3개** 결정 (예: "강릉 오션뷰 카페", "안목해변 추천 카페")
- [ ] 각 키워드의 검색량/경쟁도를 한 번 체크 (Naver 검색 자동완성 / Google Trends)
- [ ] 동일 메인 키워드로 이미 쓴 글이 없는지 확인 (자기잠식 방지)

## B. 제목 (Title)

- [ ] **메인 키워드를 제목 앞쪽 10자 이내**에 배치
- [ ] 30~40자 이내
- [ ] 같은 블로그 내 다른 글 제목과 중복되지 않음
- [ ] 클릭베이트("충격", "반전", "절대" 등) 사용하지 않음

## C. 본문 구조

- [ ] H2 헤딩 2~5개, 각 헤딩에 **메인/서브 키워드 자연스럽게 포함**
- [ ] 첫 문단(100~200자)에 메인 키워드 1회 이상 등장
- [ ] 본문 전체에 메인 키워드 자연스럽게 5~10회 (전체 글자 수의 1~2%)
- [ ] 키워드 스터핑(부자연스러운 반복) 금지
- [ ] 1,500자 이상 글에는 목차 삽입

## D. 이미지

- [ ] 모든 이미지에 **alt 텍스트** 입력 (메인/서브 키워드 활용)
- [ ] 이미지 파일명은 의미 있는 영문 (`gangneung-cafe-01.jpg` 형태) — 가능한 범위 내에서
- [ ] 이미지 용량 200KB 이하로 압축 (모바일 로딩 속도)
- [ ] 핵심 이미지는 가로형(1200x630) 썸네일로 별도 준비

## E. 메타 데이터

- [ ] **태그 우선순위 (총 12개 이내)** — 아래 순서로 채운다
  1. **작성 연도** (예: `2026`)
  2. **카메라** (예: `소니a7m5`, `소니a7m3`, `리코GR3`) — 첫 사진의 EXIF에서 자동 식별, 식별 불가 시 사용자에게 확인
  3. **카테고리별 필수 태그** (2026-07-19 확정)
     - 맛집 카테고리 → `맛집`, `사진` 반드시 포함
     - 국내여행/해외여행 카테고리 → `국내여행`(국내) 또는 `해외여행`(해외), `사진` 반드시 포함
     - 카페·디저트 / 쇼핑 / 호텔리뷰 → 별도 필수 태그 지침 나올 때까지 이 단계 생략(연도+카메라 다음 바로 SEO 태그로)
  4. 나머지: 메인 키워드 + 서브 키워드 + 지역/카테고리 등 SEO 태그
- [ ] **요약(meta description)** 직접 작성. 첫 100~150자에 핵심 정보 압축
- [ ] 카테고리는 한 글 = 한 카테고리

> 태그 우선순위는 `blog_tag_rules` 결정(2026-05-09 연도·카메라, 2026-07-19 카테고리 필수 태그 추가)을 그대로 반영한 것. 카페·쇼핑·호텔리뷰의 필수 태그 확장 여부는 아직 미정 — 결정되면 이 섹션과 `AGENTS.md` 8절, `scripts/tistory_harness.py`를 함께 갱신할 것.

## F. 내부/외부 링크

- [ ] **내부 링크 1~3개**: 같은 카테고리의 이전 글 또는 관련 정보 글
- [ ] **외부 링크 0~2개**: 공식 사이트(식당/제품/관광지)로 연결
- [ ] 모든 외부 링크는 새 창(target="_blank") 열기

## G. 모바일·가독성

- [ ] 모바일에서 한 줄에 들어오는 문장 길이 (60자 이내)
- [ ] 한 문단 5줄 이내
- [ ] 강조는 **굵게** 또는 인용블록만 사용. 글자색·크기 변경은 자제
- [ ] 표는 가로 스크롤이 필요하지 않은 폭으로 작성

## H. 발행 직후

- [ ] Google Search Console에서 색인 요청 (URL 검사)
- [ ] Daum/Kakao 색인 자동 처리 (티스토리 기본)
- [ ] Naver 웹마스터도구에 등록되어 있는지 확인 (분기별 점검)
- [ ] 발행 후 24시간 내 검색 결과 노출 여부 확인

## 자기 점검: 한 번에 다 통과해야 발행

위 항목 중 **A·B·C·D·E·G**는 **필수**. F·H는 권장.
