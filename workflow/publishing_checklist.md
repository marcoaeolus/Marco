# 발행 워크플로우 & 체크리스트

글 하나를 발행할 때 따라가는 단계입니다. 매번 이 순서를 따르면 누락이 줄어들고 품질이 일정해집니다.

## 단계 0. 기획 (1~2일 전)

- [ ] `calendar/idea_bank.md`에서 다음 글 주제 픽
- [ ] `specs/blog_profile.md`로 카테고리·타겟·키워드 재확인
- [ ] **메인 키워드 1개 + 서브 키워드 2~3개** 결정
- [ ] 동일 키워드로 이미 쓴 글 없는지 검색 (자기잠식 방지)
- [ ] 발행 예정일을 `calendar/content_calendar.md`에 잡아두기

## 단계 1. 초안 (작성 시작)

- [ ] `templates/`에서 카테고리 맞는 템플릿 복사
- [ ] 파일명: `drafts/YYYYMMDD_카테고리_핵심키워드.md` (예: `drafts/20260512_travel_gangneung.md`)
- [ ] 메타 정보 박스 먼저 채우기 (제목 후보 3개 포함)
- [ ] 핵심 정보 박스 채우기 (사실 정보 — 가격·시간·위치)
- [ ] 본문 골격 (H2 헤딩) 잡기

## 단계 2. 본문 작성

- [ ] `guidelines/02_post_structure.md`의 4-Block 골격 따라가기
- [ ] 각 H2 섹션 채우기
- [ ] 단점·아쉬운 점 섹션 작성 (필수)
- [ ] 마무리·재방문 의사·추천 대상 작성

## 단계 3. 톤·SEO 검수

- [ ] `guidelines/01_tone_and_manner.md` NG 체크리스트 통과
  - 광고성 형용사 5회 이하
  - 단점 1개 이상
  - 같은 어미 3회 연속 없음
  - 협찬/제휴 고지 (해당 시)
- [ ] `guidelines/03_seo_checklist.md` A~E 항목 모두 통과
  - 메인 키워드 위치·빈도
  - 제목 30~40자
  - H2 2~5개
  - 첫 문단 키워드 등장
- [ ] 글자 수 카테고리별 최소치 충족

## 단계 4. 이미지 작업

- [ ] 사진 선별 (카테고리별 권장 장수)
- [ ] 각 이미지 200KB 이하로 압축 (TinyPNG / Squoosh)
- [ ] 파일명을 의미 있는 영문으로 (`gangneung-cafe-01.jpg`)
- [ ] 외부 이미지 사용 시 출처 캡션 작성
- [ ] 인물(동행/직원) 식별 가능한 사진은 모자이크
- [ ] 썸네일(대표 이미지) 1장 별도 준비

## 단계 5. 티스토리에 옮기기 (마크다운 복붙 방식)

> **원칙**: AI가 자동 입력하지 않는다. 사진·메타 입력은 어차피 사용자 몫이라 자동화 효과 < 토큰 비용.
> AI는 `_FOR_TISTORY.md` 파일 한 장으로 정리해주고, 사용자가 화면에서 복붙·입력한다.

- [ ] AI가 만든 `drafts/{날짜}_..._FOR_TISTORY.md` 열기 (메타 박스 + `▼` 본문 분리되어 있음)
- [ ] 티스토리 글쓰기 화면 우상단 **`기본모드` → `마크다운`** 으로 전환
- [ ] `▼` 아래 본문 전체 복사 → 마크다운 에디터에 붙여넣기
- [ ] 사진 자리(`[사진 N — …]`)에 사진 업로드 + alt 텍스트 입력 → 자리표시자 줄 삭제
- [ ] 1,500자 이상 글에는 `[목차]` 매크로 삽입
- [ ] 광고 위치 점검 (본문 상·중·하 + 사이드, 최대 4개)

## 단계 6. 메타 데이터 입력

- [ ] **카테고리** 선택 (한 글 = 한 카테고리)
- [ ] **태그** 5~10개 입력
- [ ] **요약(메타 디스크립션)** 직접 작성 (100~150자)
- [ ] **공개 설정** 확인 (공개)
- [ ] **댓글 / 트랙백** 정책 확인

## 단계 7. 발행 직전 최종 검수

- [ ] 모바일 미리보기로 확인 (한 줄 길이, 이미지 표시)
- [ ] PC 미리보기로 확인
- [ ] 외부 링크는 새 창 열림 확인
- [ ] 오타 검수 (한국어 맞춤법 검사기 1회)
- [ ] 협찬 고지 등 의무 표기 누락 없는지 마지막 확인

## 단계 8. 발행

- [ ] **발행** 클릭
- [ ] URL 확인 (퍼머링크가 키워드를 반영하는지)
- [ ] 본문 자체가 SNS 공유 시 어떻게 보이는지 1회 확인 (메타 OG 이미지)

## 단계 9. 발행 후 24시간 내

- [ ] **Google Search Console**에서 URL 색인 요청
- [ ] **Naver 웹마스터도구**에 노출 확인 (분기별 점검 포함)
- [ ] 첫 6시간/24시간 방문자 / 검색어 모니터링
- [ ] `calendar/content_calendar.md`에 결과 기록 (URL · 메인 키워드 · 초기 반응)

## 단계 10. 발행 후 1주일

- [ ] 검색 노출 순위 점검 (메인 키워드)
- [ ] 댓글 답변 (있는 경우)
- [ ] 잘 된 글의 패턴은 `templates/`에 반영 (월 1회 정리)
- [ ] 부진한 글은 제목/메타/이미지 보완(리라이트) 후보로 마킹

---

## 자주 빠뜨리는 6가지 (가장 많이 놓치는 것들)

1. 이미지 alt 텍스트 누락
2. 협찬/제휴 고지 누락
3. 단점 섹션 누락
4. 메타 디스크립션 자동 생성에 맡김 (직접 써야 SEO 효율↑)
5. 글 발행 후 색인 요청 안 함 (Google Search Console)
6. content_calendar에 발행 결과 기록 안 함 (피드백 루프 단절)
