# 주말 글 작성 루틴

본업(나날이스튜디오 COO)에 부담 없이, **주말 1회 일괄 작성 → 한 주 분량 예약 발행** 페이스로 운영한다. 평일에는 사진·메모만 쌓고, 글쓰기는 주말에 몰아서.

## 0. 페이스 기준

- 주 발행 목표: 2~3회 (월 8~12편)
- 주말 1회 작업으로 **3~7편** 작성 후 예약 → 1~2주 분량 확보
- 예약 발행 슬롯 (4개 중 선택):
  - 월요일 09:00 (출근 시간)
  - 화요일 18:00 (퇴근 시간)
  - 목요일 09:00
  - 금요일 18:00

## 1. 평일 — 자료 쌓기 (다녀온 직후, 5~10분)

다녀온 곳을 **그날 또는 그 주 안에** 다음 처리:

1. **사진 정리** — SD카드/카메라 → 노트북 폴더로 이동
   - 폴더명: `/블로그사진/YYYYMMDD_카테고리_슬러그/`
   - 예: `/블로그사진/20260125_food_konkuk_goheungsoondae/`
   - 이 단계에서 사진 선별까지 (12장 내외로 컷)
2. **idea_bank.md 추가** — 한 줄 + 사진 폴더 경로
   - 형식: `[카테고리] 상호명 (지역) — 사진 폴더 경로`
3. **메모 한 줄** — 좋았던/아쉬운 점 키워드만 짧게
   - 일주일 지나면 디테일 까먹기 쉬움. 다녀온 날 짧은 메모 필수

## 2. 주말 작업 (토요일 또는 일요일, 2~6시간)

### 단계 1. 글감 픽 (10~15분)

- idea_bank.md에서 이번 주말 작성할 3~7개 픽
- 카테고리 균형 점검 — 여행 : 맛집·카페 : IT·일상 = 4 : 3 : 3
- content_calendar.md에 예약 발행 일정 미리 잡기 (위 4슬롯에서)

### 단계 2. 글마다 작성 (글 1개당 ~50분)

```
[정보 입력 10분] → [AI 마크다운 초안 5분] → [검토 10분] → [티스토리 작업 15~20분] → [예약 발행 5분]
```

#### 2-1. 정보 입력 (10분) — AI에게 한 묶음으로 전달

```
[카테고리] 맛집 / 카페·디저트 / 여행 / IT / 사진·일상

[장소·상호] (예: 고흥순대국 머리고기)

[위치] (지하철역 도보 ○분 또는 도로명)

[방문일 + 시간대] (예: 2026-01-25 평일 저녁 7시)

[동행] (혼자 / 2명 / 가족 / 회식 등)

[시킨 것 + 가격] (한 줄에 하나)

[좋았던 점] 1~3개

[아쉬웠던 점] 1~2개 (필수)

[재방문 의사] (5점 만점 + 한 줄 이유)

[사진 폴더 경로 또는 첨부]
```

> 카테고리별 추가 항목은 `templates/{카테고리}_post.md` 참고 (여행은 동선·예산, IT는 스펙·비교 등).

#### 2-2. AI 마크다운 초안 (자동, 5분 대기)

AI가 자동으로 처리:

- 첫 사진 EXIF → 카메라 태그 자동 식별 (`소니a7m5` / `소니a7m3` / `리코GR3` 등)
- 간격 규칙 적용 (사진 ↔ 글 1줄, 챕터 사이 2줄)
- 본문 끝 `— by Marco` 시그니처
- SEO 체크리스트(메인 키워드 첫 문단·H2 분포·태그) 통과
- 메타 박스(제목 후보 3안 / 카테고리 / 태그 12개 / 메타 디스크립션) 위쪽에 정리
- 결과: `drafts/{날짜}_{카테고리}_{슬러그}_FOR_TISTORY.md`

#### 2-3. 검토 (10분)

- 톤 적합성 (광고 같지 않은지, 단점 명시되어 있는지)
- 사실 확인 (가격·영업시간·정확한 메뉴명)
- 제목 3안 중 선택

#### 2-4. 티스토리 작업 (15~20분)

- 글쓰기 → 마크다운 모드 전환
- `▼` 아래 본문 복붙
- 사진 12장 업로드 + alt 텍스트 입력 → 자리표시자 줄(`[사진 N — …]`) 삭제
- 카테고리 · 태그 · 메타 디스크립션 입력

#### 2-5. 예약 발행 (5분)

- 발행 옵션 → "예약" 선택 → 위 4슬롯 중 하나 선택
- content_calendar.md에 URL · 예약 일시 기록

### 단계 3. 마무리 (10분)

- content_calendar.md 업데이트 (이번 주말 픽한 글 3~7개 다 기록)
- 다음 주말 후보 idea_bank.md 한번 훑어보기
- 사진 폴더 백업 (구글 드라이브 등)

## 3. 시간 합계 (참고용)

| 작성 편수 | 예상 소요 | 비고 |
|---|---|---|
| 3편 | ~2.5시간 | 토요일 오전 한 번에 |
| 5편 | ~4.5시간 | 토요일 반나절 |
| 7편 | ~6시간 | 토·일 분산 또는 토요일 종일 |

## 4. 박민재 님이 매번 입력해야 할 정보 (체크리스트)

```
□ 카테고리 픽
□ 상호·장소명
□ 정확 위치 (지하철 출구 + 도보 분 / 도로명)
□ 방문일·시간대
□ 동행
□ 시킨 것·한 일 + 가격·비용
□ 좋았던 점 1~3
□ 아쉬웠던 점 1~2 (필수)
□ 재방문 의사 (5점 + 한 줄 이유)
□ 사진 폴더 경로 (또는 첨부)
□ (협찬·제휴라면) 고지 여부
```

## 5. AI가 자동으로 처리하는 것

- 마크다운 초안 작성 (Marco 풍 ~다체)
- 4-Block 구조 적용 (도입 / 정보박스 / 본문·H2 / 마무리)
- 카메라 태그 EXIF 식별 + 연도·카메라 우선 태그 배치
- 사진 ↔ 본문 ↔ 챕터 간격 룰 적용
- `— by Marco` 시그니처
- SEO 체크리스트(키워드 분포·H2 갯수·길이) 자동 점검
- 제목 3안 + 메타 디스크립션 + 태그 12개 추천
- 단점 누락 검사

## 6. 흔한 함정 (피해야 할 것)

- ❌ 평일에 사진 정리 미루기 → 주말에 폴더 찾는 데 시간 다 씀
- ❌ 디테일 까먹은 채로 작성 → 글이 두루뭉술해져서 SEO·신뢰도 둘 다 손해
- ❌ 같은 카테고리 5편 연속 발행 → 단조로움. 카테고리 균형 점검 필수
- ❌ 카메라 태그 / 연도 태그 빠뜨림 → 가이드 룰 위반, 매번 자동 적용 의식
- ❌ 협찬·제휴 글 고지 누락 → 정책 위반 + 신뢰 손상
